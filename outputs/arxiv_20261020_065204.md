**中文翻译**
- 标题：从成人肾脏肿块到儿童Wilms瘤：评估MRI肾脏病变分割的跨域泛化能力
- 摘要：儿童肿瘤学的深度学习分割模型通常基于小型单中心队列训练，而成人疾病（如肾癌）则存在规模大得多的数据集。基于成人肾脏病变训练的模型能否泛化至儿童Wilms瘤仍不明确。我们在单一序列T1或T2加权成人肾脏MRI上训练了一个分割模型，并在留出的成人测试集和儿童Wilms瘤队列上进行评估，在儿童队列中与儿童专用nnU-Net进行比较。分割性能采用Dice相似系数（DSC）和第95百分位Hausdorff距离进行量化。在成人测试集上，该模型对肾脏病变的中位DSC为0.86。在儿童队列上，成人训练的模型中位DSC为0.85，而儿童专用模型为0.90。尽管在年龄、解剖结构和肿瘤类型上存在差异，成人训练的模型在儿童Wilms瘤上表现出有前景的性能，与儿童专用模型相比中位DSC仅有适度差异。然而，未能证明非劣效性，这凸显了儿童训练数据的价值。在未来的工作中，可探索微调策略。

- 标题：门控差分线性注意力：用于高保真医学分割的线性时间解码器
- 摘要：医学图像分割要求模型在保持精细解剖边界的同时，仍适合临床部署。Transformer 能捕捉长程依赖，但注意力成本呈二次方增长；CNN 高效，但在全局推理方面效果较弱。线性注意力提供 \(\mathcal{O}(N)\) 的扩展性，但常产生弥散的特征聚合，削弱对边界敏感的预测。我们提出一种用于医学图像分割的门控差分线性注意力混合器。其全局路径——门控差分线性注意力（GDLA）——在互补的查询/键子空间上对两个核化注意力分支执行差分相减以抑制冗余响应，并采用数据相关门控进行 token 细化。一个并行的、带深度卷积的局部 token 混合分支增强邻域交互以实现更好的细化，两个分支在保持 \(\mathcal{O}(N)\) 复杂度的同时进行融合。当实例化于基于预训练金字塔视觉 Transformer（PVT）的编码器—解码器模型时，\name 在涵盖 CT、MRI、超声和皮肤镜的所评估 2D 医学分割基准上取得最先进结果，相较密切相关的基线具有有利的精度—效率权衡。代码公开于 \href{https://github.com/xmindflow/gdla}{https://github.com/xmindflow/gdla}。

- 标题：Primus：强制注意力机制用于3D医学图像分割
- 摘要：Transformer在多个领域取得了显著成功，但其在3D医学图像分割中的影响仍然有限，卷积网络仍在主要基准中占据主导地位。在本工作中，(A) 我们分析了当前基于Transformer的分割模型，并识别出关键缺陷，特别是它们对卷积块的过度依赖。此外，我们证明在某些架构中，性能不受Transformer缺失的影响，从而表明其有效性有限。为应对这些挑战，我们摒弃混合架构，并(B) 引入以Transformer为中心的分割架构，称为Primus和PrimusV2。Primus利用高分辨率token，结合位置嵌入和模块设计的进展，以最大限度地发挥其Transformer块的作用，而PrimusV2通过迭代式patch嵌入对其进行了扩展。通过这些调整，Primus超越了当前基于Transformer的方法，并与默认的nnU-Net相竞争，而PrimusV2则超越了它，并在九个公共数据集上与ResEnc-L和MedNeXt架构等最先进的CNN持平。由此，我们引入了首个具有竞争力的以Transformer为中心的模型，使Transformer在3D医学图像分割中达到最先进水平。代码可在此处获取：https://github.com/MIC-DKFZ/nnUNet/blob/master/documentation/primus.md。

**中文翻译**
- 标题：用于医学图像分割的焦点调制与双向特征融合网络
- 摘要：医学图像分割对疾病诊断、治疗规划和疾病发展监测等临床应用至关重要，因为它能提供直接影响治疗决策的解剖结构精确形态和空间信息。卷积神经网络对图像分割有显著影响；然而，由于卷积操作是局部的，捕获全局上下文信息和长程依赖仍然具有挑战性。这一限制影响了其精确分割具有复杂边界和多种尺寸结构的能力。由于Transformer利用自注意力方法高效捕获全局上下文和长程依赖，将基于Transformer的架构与CNN集成是克服这些挑战的可行方法。为应对这些挑战，我们提出了用于医学图像分割的焦点调制与双向特征融合网络，本文其余部分称为FM-BFF-Net。该网络结合了卷积和Transformer组件，采用焦点调制注意力机制来细化上下文感知，并引入双向特征融合模块，使编码器和解码器表示能够在不同尺度上高效交互。通过这一设计，FM-BFF-Net增强了对病变大小、形状和对比度变化的边界精度和鲁棒性。在包括息肉检测、皮肤病变分割和超声成像在内的八个公开数据集上进行的大量实验表明，FM-BFF-Net在Jaccard指数和Dice系数上持续超越近期最先进方法，证实了其在不同医学成像场景中的有效性和适应性。

**中文翻译**
- 标题：TopoMamba：面向异构医学视觉媒体分割的拓扑感知扫描与融合
- 摘要：视觉状态空间模型（SSM）在医学图像分割中已展现出强大潜力，但其有效性常受两个实际问题限制：轴向偏置的扫描顺序削弱了对斜向和弯曲结构的建模，而朴素的多分支融合往往会放大冗余响应。我们提出 TopoMamba，一种用于分割异构医学视觉媒体的拓扑感知扫描与融合框架。该方法将对角/反对角 TopoA-Scan 分支与标准 Cross-Scan 分支相结合，以提供互补的结构先验，并引入 ScanCache——一种设备感知的缓存机制，可在重复出现的分辨率上摊销显式扫描索引的构建开销。为高效融合异构扫描特征，我们进一步提出轻量级 HSIC 门控，利用依赖感知的标量门控规则调节分支交互。我们还实例化了体数据 TopoMamba-3D，用于实际的 3D 临床分割。在 Synapse CT、ISIC 2017 皮肤镜和 CVC-ClinicDB 内窥镜上的实验表明，TopoMamba 在强 CNN、Transformer 和 SSM 基线上持续提升分割质量，尤其在胰腺和胆囊等细薄或弯曲目标上增益明显，同时在动态输入分辨率下保持良好的部署效率。这些结果表明，拓扑感知扫描顺序与轻量级依赖感知融合构成了一种有效且实用的医学多媒体分割设计。代码将公开。
