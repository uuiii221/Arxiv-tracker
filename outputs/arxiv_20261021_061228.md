### [中文]
**中文翻译**
- 标题：面向不完整多模态脑肿瘤分割的渐进式多尺度肿瘤状态记忆
- 摘要：脑肿瘤分割利用互补的磁共振成像（MRI）序列，但在实际应用中某些序列可能缺失。序列缺失会改变用于分割不同肿瘤区域的信息。融合方法可支持不同的输入子集。然而，多尺度融合本身并不能说明如何保留和更新肿瘤证据以指导后续阶段的融合。我们提出一种渐进式多尺度肿瘤状态记忆网络（PMTM），用于从T1ce、T1、FLAIR和T2的任意非空子集进行分割。PMTM在编码器各阶段为当前受试者维护一个紧凑状态。在每个阶段，我们使用分配图将空间特征池化为每个可用模态的有序证据向量。我们在可用模态上对这些向量取平均，并由一个学习门控将该证据与先前状态结合。更新后的状态指导该阶段的残差融合，并用于下一阶段的状态更新。模态令牌混合器还在每个阶段对可用模态间的交互进行建模。我们在全部四个阶段对分配图施加语义监督。我们在BraTS2018、BraTS2020和BraTS2023 GLI上对所有15个非空模态子集评估PMTM。在三个肿瘤区域和15个子集上平均，PMTM在BraTS2018、BraTS2020和BraTS2023 GLI上分别取得75.31%、77.54%和80.47%的Dice分数。在我们的实验中，这些分数在每个数据集上均高于RobustSeg、RFNet和mmFormer。组件消融和内部状态分析在BraTS2020上进行。

## 2. SlimFormer++: Token Mixing Where It Matters for Efficient 3D Medical Image Segmentation

- First：2026-10-18T19:19:08+00:00；Latest：2026-10-18T19:19:08+00:00

- PDF：https://arxiv.org/pdf/2610.25488v1
- Code：https://github.com/WHHHHHY822/SlimFormerPlusPlus, https://huggingface.co/huggingface, https://huggingface.co/docs/hub/spaces
### [中文]
**中文翻译**
- 标题：SlimFormer++：在关键位置进行Token混合的高效3D医学图像分割
- 摘要：为确定体积分割网络中何处需要计算，我们分析了块级冗余和分阶段token混合器的贡献。中心核对齐揭示，代表性卷积、混合和Transformer式分割网络的块内输入-输出表征相似度很高。相似度引导的剪枝将其参数量减少39-75%，而平均Dice下降不到0.4个百分点。为考察块内的token混合器，我们引入解剖关系失真，量化绕过混合器如何扭曲标注解剖位置之间的特征关系。应用于未剪枝的候选架构时，中心核对齐表明中间编码器混合器存在高表征冗余，而解剖关系失真显示其贡献很小，瓶颈混合器贡献最大。这些发现促成了SlimFormer++，其在第一个编码器阶段使用带窗口化Mamba混合的选择性混合块，在更深阶段仅使用残差通道MLP。在瓶颈处，增强混合以与体素数成线性的代价，将相似度加权的稀疏长程上下文注入深度卷积的轴向抽头。在八个公开CT、MRI和超声数据集（1,809例）上与12个基线评估相比，SlimFormer++以最少的参数量（598万）实现了最高平均Dice（87.84%）和最低平均HD95（6.50 mm）。这些结果支持将阶段感知token混合作为改善体积分割精度-效率权衡的设计策略。源代码见https://github.com/WHHHHHY822/SlimFormerPlusPlus

## 3. Reliability-Preserving Compression for Deployable Medical Image Segmentation
- Authors：Sagar Kumar, Shailja Sharma, Tirthajit Baruah, Punit Rathore
- First：2026-10-18T18:44:14+00:00；Latest：2026-10-18T18:44:14+00:00

- PDF：https://arxiv.org/pdf/2610.25460v1
- Code：https://huggingface.co/huggingface, https://huggingface.co/docs/hub/spaces
### [中文]
**中文翻译**
- 标题：面向可部署医学图像分割的可靠性保持压缩
- 摘要：预训练医学分割模型的后训练压缩通常采用量化、剪枝或蒸馏来减小模型尺寸和计算成本。现有医学分割量化研究主要评估Dice、模型大小、内存和延迟，但这对于安全关键应用并不完整，因为压缩模型还应保留指示不可靠预测的不确定性信号。我们在压缩MRI/CT分割中研究该问题，并形式化说明为何Dice可保持稳定而不确定性发生变化。受此失效模式启发，我们提出分数引导的聚合验证混合精度（SGAV-MP），一种在可靠性约束下选择层精度的后训练压缩框架。SGAV-MP用紧凑的收益-风险分数对量化操作排序，并仅在校准集上完成全模型可靠性验证后才接受。在五个2D骨干网络和三个3D基准上，SGAV-MP保持FP32级Dice和高不确定性图一致性，在2D中实现$3.59\times$--$7.8\times$压缩，在3D中实现$4.73\times$--$7.82\times$压缩。我们还单独报告后端支持的TensorRT部署测量，以区分运行时执行与可靠性保持的存储压缩。

## 4. Shifting Adaptation from Weight Space to Memory Space: A Memory-Augmented Agent for Medical Image Segmentation

- PDF：https://arxiv.org/pdf/2603.05873v2

### [中文]
**中文翻译**
- 标题：将适应从权重空间转向记忆空间：一种用于医学图像分割的记忆增强智能体
- 摘要：医学图像分割是临床工作流程的基础，然而在单一数据集上训练的模型往往难以跨机构、扫描仪或患者群体泛化。尽管视觉基础模型在应对这一挑战方面展现出巨大潜力，但其部署通常需要针对特定任务进行微调，这在联邦学习中引入了大量通信开销，并阻碍了部署期间知识的持续演化。在本工作中，我们提出了一种记忆增强分割智能体（MemSeg-Agent），它将适应从权重空间转向记忆空间，从而在统一架构内实现少样本学习、联邦监督学习和测试时适应。MemSeg-Agent 以轻量级的静态记忆、少样本记忆和测试时工作记忆为固定骨干网络提供条件，这些记忆由智能体控制器动态组合。在联邦设置中，我们更新紧凑的记忆单元而非模型参数，从而大幅降低通信开销。在四个公开数据集上的实验证明了其强劲的性能以及对域偏移的鲁棒性：仅静态记忆即可在高参数效率下达到或超越强监督基线，而测试时工作记忆无需微调即可进一步提升域内和跨域性能。总体而言，MemSeg-Agent 为智能体 AI 时代可扩展且自适应的医学图像分割引入了一种新范式。

- 标题：CLC-YOLO：用于实时泄漏感知乳腺超声病灶分割的紧凑通道门控原型网络
- 摘要：可靠的乳腺超声病灶分割需要准确的边界以及能够防止患者或重复图像跨越数据划分的评估。我们提出通道局部对比（CLC），这是对YOLO26分割原型头的紧凑改进。CLC添加了一个由64个零初始化、有界通道门控控制的固定局部高通残差。在四个乳腺超声数据集上，各以五个匹配折比较基线与CLC。BUS-BRA采用患者不相交的外层测试并单独进行内部验证。BUS-UCLM和BrEaST采用患者分组验证折；BUSI因缺少患者标识符而采用重复组件分组。在BUS-BRA、BUS-UCLM、BUSI和BrEaST上，组宏Dice分别提高1.68、3.11、1.12和2.45个百分点。仅BUS-BRA的配对95%置信区间排除零。CLC增加64个参数和0.0049吉浮点运算（GFLOPs）。在640像素、单T4、批大小为一、16位浮点（FP16）TensorRT图时间下，CLC为2.1478毫秒，基线为2.0512毫秒，不含预处理和后处理。CLC在全部四个数据集上提高了组宏Dice，实测T4前向传递开销为0.0966毫秒。代码：https://github.com/mfazrinizar/CLC-YOLO
